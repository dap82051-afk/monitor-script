# Monitor Script

Скрипт мониторит основное для сервера: Диски, память, системные службы, сервисы(nginx, docker и другие)

## Что делает?

1) Проверяет использование диска
2) Проверяет использование оператвной памяти
3) Проверяет статус сервисов (nginx, docker, ssh и т.д.)
4) Логирует все в файл (временно, позже в телеграмм)
